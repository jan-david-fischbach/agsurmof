I'm sending you the data for figure 6. Please take a look. You'll see that in the data structure there is a column called knVal—these are two optical fields for the unperturbed system (the regular one and its negative conjugate) for each thickness value. Then there is a cell Vnm, where each element is the integral  \int E_n E_m  dr. Notice there are three values here—one integral for each layer—and also note that this integral doesn't include \sigma(r). I deliberately did it this way so that later, when constructing the Hamiltonian (H), I can simply multiply the necessary part of Vnm by the corresponding layer's \sigma constant.

There is also a column knNew, which represents the eigenvalues of the perturbed system in the single mode approximation(4x4 matrix). KnShift denotes the resonance shift, or in other words, the first diagonal element of the matrix H. The parameter coupl_coeffs contains the elements of the matrix H, specifically iV_{11}^{p}, where p is material pole.
